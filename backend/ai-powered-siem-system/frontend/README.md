# AI-Powered SIEM System - Frontend

This project is the frontend component of an AI-powered Security Information and Event Management (SIEM) system. It is designed to provide a user-friendly interface for administrators to monitor security events, manage rules, and analyze logs effectively.

## Features

- **Dashboard**: An overview of the system's status and analytics.
- **Tuning Interface**: A set of tools for administrators to create and modify rules, adjust thresholds for alerts, and tune AI decision-making parameters.
- **Log Viewer**: A component for displaying logs for review and analysis.
- **Responsive Design**: The application is designed to be responsive and accessible on various devices.

## Getting Started

To get started with the frontend development, follow these steps:

1. **Clone the Repository**:
   ```bash
   git clone <repository-url>
   cd ai-powered-siem-system/frontend
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Run the Application**:
   ```bash
   npm start
   ```

4. **Open in Browser**:
   Navigate to `http://localhost:3000` to view the application.

## Folder Structure

- **public/**: Contains static files such as `index.html`, `favicon.ico`, and `manifest.json`.
- **src/**: Contains the source code for the application.
  - **components/**: Reusable components for the application.
  - **pages/**: Page components that render specific views.
  - **services/**: API service functions for backend communication.
  - **types/**: TypeScript types and interfaces.
  - **App.tsx**: Main application component.
  - **index.tsx**: Entry point for the React application.
